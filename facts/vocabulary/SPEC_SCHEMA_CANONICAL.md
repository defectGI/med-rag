# ACME SPEC SCHEMA — CANONICAL (RAG / unified DB)

433 unique canonical keys, 11 functional categories. This dictionary
is the closed key vocabulary of the unified `specs` table; `family` is
a metadata column on each row, not a table split. Shared keys are used
across all families with a SINGLE definition/kind/unit.

`scope`: **shared** = present in 2+ families (universal, most queried);
**family** = scoped to a single family.
